# Леса-вышки

Новая адаптивная версия сайта lesa-vyshki.kz. HTML, CSS и JavaScript без клиентских зависимостей. Исходные файлы сайта — в `dist/`.

**Сайт:** https://kolokolchi.github.io/lesa-vyshki/

**Репозиторий:** https://github.com/Kolokolchi/lesa-vyshki

## Локальный просмотр

```sh
npm install
npm run dev
```

Открыть http://localhost:4173. Сервер слушает только локальный компьютер. Для другого порта задайте переменную окружения `PORT`.

## Что сделано

- Логотип из рам и диагональных связей, обычная и светлая SVG-версии с буквами в кривых, favicon.
- Архитектурная фотография первого экрана, созданная imagegen; на сайте она отмечена как визуализация.
- Каталог реальных моделей с характеристиками, раскрываемыми подробностями и ссылками на документы.
- Интерактивная изометрическая сборка лесов и вышки: ползунок добавляет и снимает секции с анимацией. Модель условная, не инструкция по монтажу.
- Для лесов: длина 3–90 м, высота 2–60 м; площадь и стартовый ориентир по цене. Для вышек схема показывает высоты 2,4–21,6 м с шагом 1,2 м, а окончательную высоту и комплект подтверждает менеджер.
- Запрос с выбранными размерами и городом открывается в WhatsApp. Отправку выполняет посетитель; сайт не притворяется, что заявка уже доставлена.
- Доставка, FAQ, реальные контакты Астаны и Алматы, мобильное меню, управление клавиатурой и поддержка reduced motion.

## Проверка

```sh
npm run check
npm test
```

Для тестов нужен Chromium из Playwright. Если его нет: `npx playwright install chromium`. Запускайте `npm test` при работающем локальном сервере.

Проверяются загрузка ресурсов, ошибки JavaScript, добавление и снятие секций, быстрые изменения высоты, клавиатура, переключение моделей, формирование запроса, расчёт цены, другой город, FAQ, меню, reduced motion и отсутствие горизонтального переполнения на ширинах 320, 360, 390, 768, 1024 и 1440 px. Тест не отправляет сообщения: открытие WhatsApp перехватывается. Скриншоты сохраняются в `artifacts/`.

## Ресурсы и контент

`dist/assets/logo.svg` — основной логотип. `logo-light.svg` — версия для тёмного фона. `favicon.svg` — знак. Генератор букв в кривых: `node scripts/export-logo.mjs`.

`dist/assets/scaffolding-hero.webp` — оптимизированная архитектурная визуализация первого экрана, созданная с помощью генерации изображений.

Изображения оборудования, контакты и технические характеристики взяты с https://lesa-vyshki.kz/ 16 октября 2026. Цены 2 600 ₸/м² и 99 900 ₸ — опубликованные стартовые ориентиры, не подтверждённые цены на любую комплектацию. Сроки, остатки и итоговую цену необходимо подтвердить с компанией. Для изменения расчёта лесов обновите ставку 2600 в `dist/app.js` и соответствующие тексты в `dist/index.html`.

Шрифты Manrope и Oswald размещены локально. Лицензии OFL — в `notes/licenses/`.

## Публикация

GitHub Actions автоматически публикует изменения ветки `main` на GitHub Pages. Настройки репозитория: **Settings → Pages → Source: GitHub Actions**. Процесс описан в `.github/workflows/pages.yml`; секреты для него не нужны.

Для обновления сайта измените файлы в `dist/` и отправьте изменения в `main`. Статус публикации виден во вкладке **Actions** репозитория.

```sh
npm run build
```

Команда собирает `_site/`: делает ссылки на ресурсы относительными, добавляет публичные canonical, Open Graph URL, robots.txt и sitemap.xml, разрешает индексацию. По умолчанию используется адрес GitHub Pages выше. Для другого хостинга передайте переменную `PAGES_URL` с полным HTTPS-адресом сайта и загрузите содержимое `_site/`. Node.js на хостинге не требуется.

Проверить опубликованную версию можно командой `npm test`, задав `TEST_URL` с её адресом. Тест не отправляет сообщения.

Исходный домен lesa-vyshki.kz не изменён. Ключи и серверная форма не нужны для текущего сценария через WhatsApp. Цены, наличие и комплектацию подтверждает менеджер.
